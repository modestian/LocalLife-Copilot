## 记录原则

1. “前端降级方案”只用于组件开发、演示或测试，不能视为后端验收通过。
2. 前端资源范围判断不是安全边界，直接调用接口的 401/403/404 必须由后端保证。
3. 后端解除阻塞后，需要用真实数据库和真实 API 重新执行联调，不能只依赖 Mock 组件测试。
4. 每次更新问题状态时，应同步记录验证分支、Commit、请求样例和自动化测试结果。
