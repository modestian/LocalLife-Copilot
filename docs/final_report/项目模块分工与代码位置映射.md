## 2. L（原 A）— 平台基础、数据与权限

### 2.1 责任概述

负责项目的数据底座和基础设施层：FastAPI 应用入口、配置系统、认证授权、数据库模型与迁移、会话与消息元数据、知识库文档版本管理、异步任务状态机、Outbox 事件、治理（提示词/模型版本/审计）和内容安全。

涵盖 Epic：**EP-01**（平台基础、数据与权限）

对应 Story：ST-101（安全登录与资源范围授权）、ST-102（业务元数据、异步任务与一致性）、ST-103（配置、日志与审计治理）、ST-703（安全、性能与恢复门禁）

## 3. Z（原 B）— 知识处理与混合检索 + RAG 对话与智能体

### 3.1 责任概述

负责数据从原始文件到可检索知识的全链路：多格式文件加载、DataFrame 标准化、清洗管道、文本切分、Embedding 向量化、OpenSearch 索引管理、BM25+向量双路混合检索、RRF 融合与重排；以及 LangGraph 多轮对话运行时：意图路由、约束抽取、缺参追问、RAG 生成、引用校验、会话记忆和无证据兜底；同时负责模型推理网关和 Celery 异步 Worker。

涵盖 Epic：**EP-02**（知识处理与混合检索）、**EP-03**（RAG 对话与智能体）

对应 Story：ST-201（多源知识导入与生命周期管理）、ST-202（权限安全的混合检索）、ST-301（可溯源多轮 RAG 推荐）、ST-302（OpenAI/WebSocket 与安全工具调用）
