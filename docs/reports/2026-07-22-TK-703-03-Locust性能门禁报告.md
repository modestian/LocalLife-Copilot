# TK-703-03 Locust 性能门禁报告

## 1. 验收范围

本报告对应 `TK-703-03`：使用 Locust 测量已鉴权 API、权限安全的混合检索和 OpenAI 兼容 SSE 首包 P95，并按 `ST-703` 的 API `< 500 ms`、检索 `< 300 ms`、首包 `≤ 2 s` 门槛自动判定。

本次实现基线为 `main` 提交 `434ccc8f54dbbc71009738a2287f990506c7f100`，验证环境为 Windows、Python 3.13.14、Locust 2.46.1。

## 2. 交付内容

- `backend/performance/locustfile.py` 对真实登录、`/api/v1/users/me`、`/api/v1/search` 和 `/v1/chat/completions` 发起请求。SSE 指标记录从请求发出到首个非空 `data:` 帧的墙钟耗时，不以响应头时间冒充首包时间。
- `backend/performance/gate.py` 读取 Locust CSV，对场景缺失、样本不足、失败请求、缺少 P95 和延迟越界执行失败关闭判定，并输出 JSON 与 Markdown。
- `scripts/run_tk703_performance.ps1` 提供一键无界面压测、原始 CSV/HTML 归档和门禁判定；账号密码只从当前进程环境读取。
- `backend/tests/test_performance_gate.py` 覆盖严格/含等号边界、失败请求、缺失场景和样本不足。

完整执行步骤和参数见[TK-703-03 Locust 性能门禁](../development/TK-703-03-Locust性能门禁.md)。
