# TK-703-02 安全专项验收报告

## 1. 验收范围

本报告对应 `TK-703-02`：执行越权、Token、限流、恶意上传、注入和日志测试，并覆盖 `ST-703` 验收准则中的横向越权、Token 重放、登录限流、恶意文件、Prompt Injection、敏感输出和日志泄密场景。

本次基线为 `main` 提交 `99973474c0b3801ae279a451671b66d8387a3b10`，执行环境为 Python 3.13.14。性能压测、MySQL/OpenSearch 对账与恢复演练分别属于 `TK-703-03`、`TK-703-04`，不在本报告的完成判定范围内。

## 2. 本次补齐的安全控制

- 登录接口按规范化账号与客户端 IP 的 SHA-256 摘要计数，不在 Redis 键或日志中保存原始账号、IP；达到阈值后返回 `429 AUTH_RATE_LIMITED` 和 `Retry-After`，成功登录会清零计数。
- 生产环境使用 Redis Lua 脚本原子执行失败计数与 TTL 初始化，默认阈值为 5 次、窗口为 300 秒，并支持环境变量覆盖。
- 文档上传在建档和写盘前校验路径、扩展名、MIME、PDF/Office 文件签名、文本二进制内容、Office 宏与可执行载荷、压缩包路径穿越、条目数量、解压大小和高压缩比。
