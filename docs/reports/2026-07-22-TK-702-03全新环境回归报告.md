## 本次发现并修复的冷启动阻断项

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 新建知识卷无法上传 | 命名卷初始属主为 root，运行 API 的非 root 用户无写权限 | 增加一次性卷准备服务并作为 API/Worker 启动前置依赖 |
| 上传 Markdown 被误判 MIME 不匹配 | 任务使用无后缀的内容哈希作为文件名 | 从受控存储 URI 提取原始后缀仅用于格式识别 |
| OpenSearch 写入失败 | 文档元数据中的普通 `location` 字符串被投影为 `geo_point` | 仅在值确为合法经纬度时投影位置字段 |
| 演示用户无法执行 RAG | 种子用户缺少演示租户上下文 | 种子用户绑定固定演示部门/租户 |
| 演示会话消息为空 | 会话没有可见分支头 | 种子会话写入当前分支消息 ID |
