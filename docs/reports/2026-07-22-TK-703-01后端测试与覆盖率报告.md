# TK-703-01 后端测试与覆盖率报告

## 1. 验收范围

本报告对应 `TK-703-01`：补齐后端单元/集成测试并生成不低于 70% 的覆盖率报告。本次基线基于 `main` 提交 `4f6d7a2e28e5230015166f9a0d0202a3f3f329b2`，使用 Python 3.13.14、Pytest 8.4.1、pytest-cov 6.2.1 和 Coverage.py 7.15.2 执行。

本报告只判定后端测试与覆盖率门禁，不替代 TK-703-02 安全专项、TK-703-03 性能测试、TK-703-04 对账恢复演练或 TK-703-05 发布签署。

## 2. 可复现命令

命令在 `backend` 目录执行：

```powershell
..\.venv\Scripts\python.exe -m pip install -e ".[dev]"
..\.venv\Scripts\python.exe -m pytest --cov=app --cov-report=term-missing --cov-report=xml:coverage/coverage.xml --cov-report=json:coverage/coverage.json --cov-fail-under=70 -q
```

CI 使用相同的 70% 失败门槛，并将 `coverage.xml` 和 `coverage.json` 作为 `backend-coverage-<commit SHA>` 产物保留 14 天。报告产物与对应 Commit 绑定，可用于后续发布门禁复核。

## 4. 跳过项说明

本地跳过项包括需要显式环境开关和已迁移服务的 MySQL/Redis 集成测试，以及需要预先生成 smoke/LoRA 训练产物的重型产物校验。CI 已提供 MySQL、Redis 和空库迁移，并启用认证、ST-102、ST-103 的数据库集成开关；训练产物类测试仍按产物是否存在决定是否执行。

跳过项未导致覆盖率门槛豁免：Pytest 仍对全部 `app` 源码统计覆盖率，低于 70% 时命令返回失败。训练产物完整性和正式训练结果属于 ST-502 证据，不作为 TK-703-01 覆盖率达标的替代条件。

## 5. 验收结论

后端完整测试无失败，全应用分支覆盖率为 74.80%，核心 Application/Domain 与 Agents/ETL 分层覆盖率均高于 70%。CI 已具备可阻断、可下载、按 Commit 追溯的 XML/JSON 覆盖率报告。

`TK-703-01` 判定：完成。
