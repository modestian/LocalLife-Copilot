# 一、双人交叉复核记录.md
## 1 基础信息
1. 任务编号：TK-401-02
2. 样本文件：benchmark_reviews.jsonl / benchmark_reviews.csv（总计100条脱敏点评）
3. 复核人员：标注员A、标注员B（独立分开标注，全程无沟通）
4. 复核依据：《美食点评三层标签标注规范 v1.0》+ label_dict_v1.json
5. 样本配比：好评40条、中性30条、差评30条
6. 复核流程：单人独立初标 → 双标结果比对 → 分歧样本统一评审 → 全量修正固化

## 2 复核执行流程
1. 分发：两名标注人员获取完全相同100条原始点评文本，独立完成三层标签标注；
2. 比对：脚本自动比对每条 `sentiment / aspect_labels / negative_reason` 三组标签，筛选不一致样本；
3. 评审：分歧样本集中对照标注规范、边界案例逐条讨论，确定唯一标准标签；
4. 修正：按照统一口径更新分歧样本标签，生成最终基准数据集；
5. 校验：修正后全量二次校验，确保全部标签符合联动约束、无非法绑定。

## 3 分歧样本统计
1. 总分歧条数：7条
2. 分歧类型分布
| 分歧类型 | 数量 | 说明 |
|--------|------|------|
| 一级情感判定分歧 | 3 | 轻微瑕疵推荐、好坏平衡文本情感归类不一致 |
| 二级维度漏标/多标 | 3 | 文本隐含维度一方漏标注 |
| 三级归因绑定争议 | 1 | 模糊负面根因是否匹配二级维度 |

## 4 典型分歧案例与统一判定口径
### 案例1
原文：分量有点少，但味道一绝，强烈推荐再来
A标注：NEGATIVE，B标注：POSITIVE
统一结论：POSITIVE（轻微瑕疵，整体明确推荐，无差评归因）

### 案例2
原文：装修好看适合拍照，人均略贵一点
A漏标price，B完整标注decoration、price
统一结论：aspect_labels=["decoration","price"]

### 案例3
原文：店内空调制冷效果一般，WiFi稳定
A未标记equipment，B标记equipment
统一结论：aspect_labels=["equipment"]

### 案例4
原文：菜品咸淡失衡，但整体尚可无强烈吐槽
A添加taste_unbalanced归因，B未添加
统一结论：sentiment=NEUTRAL，不允许填充negative_reason

## 5 复核结论
1. 经双人交叉评审、分歧统一修正后，100条样本标签完全符合《标注规范v1.0》所有约束；
2. 全部三级差评归因均存在对应二级维度，非差评样本negative_reason为空数组；
3. 所有标签编码均在label_dict_v1.json枚举范围内，无自定义文字、无重复标签；
4. 文本全部完成脱敏，不存在手机号、门店真名、精确地址等隐私信息；
5. 数据集可作为标准基准样本用于模型训练、离线评测、标注员培训。
