# TK-401-01 全套标签定义（交付文档）
## 一、任务说明
任务ID：TK-401-01
归属Story：ST-401 可解释的商家口碑基础分析
负责人：M（算法）
交付物：三层标签体系说明文档 + label_dict_v1.json 全局中英文映射字典
标签层级设计：一级情感极性标签（单选）→二级评价维度标签（多选）→三级差评归因标签（仅差评可用）

## 二、一级标签：情感极性（唯一单选，共3个）
每条点评必须且只能有1个，用于三分类模型
| 编码 | 中文名称 | 业务说明 |
| ---- | ---- | ---- |
| POSITIVE | 好评 | 整体正向，满意、推荐、复购意愿 |
| NEUTRAL | 中性 | 纯客观描述/好坏均衡无明显倾向 |
| NEGATIVE | 差评 | 整体负面，吐槽、避雷、不愿再来 |

## 三、二级标签：评价维度（全情感通用，可多选，共21个）
所有点评均可标注，文本提及对应维度即打上标签
### 1. 菜品/产品维度
`taste` 口味、`portion` 分量、`price` 性价比/价格、`freshness` 新鲜度、`appearance` 卖相/颜值、`variety` 品类选择
### 2. 环境维度
`space` 空间大小、`quiet` 安静度、`decoration` 装修氛围、`hygiene` 环境卫生、`location` 位置交通、`seating` 座位布局
### 3. 服务维度
`waiting_time` 等待时长、`attitude` 服务态度、`efficiency` 办事效率、`parking` 停车配套、`packing` 打包/配送
### 4. 活动配套维度
`discount` 优惠活动、`set_meal` 套餐、`equipment` 店内设备
### 5. 综合体验维度
`overall` 整体综合感受

## 四、三级标签：差评归因（仅sentiment=NEGATIVE可用，可多选，共19个）
每个三级标签必须匹配对应二级维度，非差评置空数组
### 菜品价格类
`taste_bad`味道难吃、`taste_unbalanced`咸淡辣度失衡、`cold_food`菜品变冷、`too_small`分量太少、`stale`食材不新鲜、`spoiled`食材变质、`overpriced`价格偏高、`false_discount`虚假优惠
### 环境类
`dirty`店内脏乱、`loud`环境嘈杂、`no_seat`无座位
### 服务类
`slow_wait`上菜等待久、`rude_staff`店员态度差、`wrong_order`上错漏单
### 配套打包类
`no_parking`无停车位、`bad_pack`打包破损漏洒、`equipment_broken`设备故障
### 时效经营类
`close_early`提前打烊、`delivery_delay`配送超时

## 五、标签联动约束规则（入库/推理强制校验）
1. sentiment != NEGATIVE 时，negative_reason 数组必须为空；
2. 每一个三级归因标签，必须存在对应的二级维度标签，否则判定非法数据拦截；
3. 所有标签严格使用固定编码，禁止自定义文字标签；
4. 二级标签可多个共存，无重复；三级标签同理不可重复。
