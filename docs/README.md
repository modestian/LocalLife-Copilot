## 维护规则

- 同一系列文档放在同一目录，并保留可排序的编号前缀。
- 移动或重命名文档时，必须同步更新仓库内的相对链接和路径说明。
- 文档中引用仓库文件时优先使用相对路径，避免写入开发者本机绝对路径。
